## 🎯 Objetivo da Habilidade

Capacitar o agente de IA a arquitetar, depurar, otimizar e gerar rotinas completas do Dynamo para o Autodesk Civil 3D com padrão profissional de engenharia (PEP BIM, normas DNIT/DER e Dynamo Player).

A habilidade cobre:
- **Terraplenagem e Otimização Heurística:** Algoritmos Genéticos e PSO para compensação de corte/aterro e greides de custo mínimo.
- **Corredores, Alinhamentos e Perfis:** Manipulação profunda da API `.NET` (`TinSurface`, `Alignment`, `Profile`, `Corridor`).
- **Redes de Drenagem e Pressurizadas:** Traçado automático, declividades mínimas normativas e dimensionamento de bueiros/poços de visita.
- **Property Sets e QTO:** Extração automatizada de quantitativos e interoperabilidade IFC/BIM.

## 🚀 Como Instalar em Qualquer Computador Novo

Para restaurar esta habilidade em qualquer máquina pessoal ou de trabalho com o Google Antigravity instalado:

1. Abra o terminal (PowerShell ou Git Bash) e execute:
```powershell
cd "$HOME\.gemini\config\skills"
git clone https://github.com/carlosoliveiraengcivil/dynamo-civil3d-skill.git dynamo-civil3d
```
2. O Antigravity detectará a habilidade automaticamente!
3. Digite no chat:
```text
Ative a habilidade dynamo-civil3d para me ajudar a criar uma rotina no Dynamo...
```
